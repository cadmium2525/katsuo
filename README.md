# 🐟 カツオのたたきサバイバー

**やたらリアルな鰹**で、迫り来る**鯖**の大群をぶっ叩く 2.5D サバイバーゲーム。
生き延びた時間がそのままスコア。何分耐えられるか競おう。

## 遊び方

| 操作 | PC | ゲームパッド | スマホ |
| --- | --- | --- | --- |
| 移動 | WASD / 矢印キー | 左スティック | 画面をドラッグ |
| 回避ステップ（一瞬無敵） | Space / Shift | A / RB | 右下 💨 |
| 鰹乱舞（ゲージ満タンで） | E / Q | B / X / LB | 右下 🐟 |
| 一時停止 | Esc / P | Start | 右下 ⏸ |
| レベルアップ | 1〜4・R（リロール）・X（スキップ）・B（封印） | 十字キー＋A | タップ |
| サウンド | M | — | 右下 🔊 |

- 攻撃は自動。鯖を倒すと**鱗（経験値）**と**小判**を落とす。
- レベルアップで 3〜4 択から強化を選ぶ。武器・パッシブはそれぞれ**最大 6 枠**。
- **連撃**：倒し続けるとコンボが伸び、経験値ボーナスと小判がもらえる。
- **鰹乱舞**：ゲージ満タンで発動。空から大量の鰹が降り注ぎ、画面の鯖をまとめて叩き潰す。
- **進化**：武器を Lv8 にして対応パッシブを持った状態で、ボス／でかいサバの宝箱を開けると進化。

### 武器と進化

| 武器 | 内容 | 進化条件 | 進化後 |
| --- | --- | --- | --- |
| 🐟 鰹のたたき | 鰹で周囲をぶっ叩く（全員の基本武器） | ✨ 鮮度 | 🌀 鰹大旋風（常に大回転＋衝撃波） |
| 🔥 藁焼きの炎 | 周囲を炙るオーラ（鰹が香ばしくなる） | 🍵 緑茶 | 🏮 藁焼き大祭（延焼） |
| 🪃 投げ鰹 | ブーメランのように鰹を投げる | 👡 草履 | 🚀 鰹ミサイル（追尾＋爆発） |
| 🍂 鰹節ショット | 削り節の貫通弾 | 🎌 ねじり鉢巻 | 🌪️ 削り節ストーム（全方位） |
| 🍋 ポン酢の沼 | 減速＋継続ダメージの沼 | 💊 DHA | 🌊 ポン酢の海（上に立つと回復） |
| 🧄 薬味オービット | にんにく・生姜・ネギが回転 | 🕸️ 漁網 | ☸️ 薬味曼荼羅（二重の輪） |
| 🔪 出刃包丁 | 進行方向へ包丁を投げる | 🛡️ 前掛け | ⚔️ 妖刀 鰹切り（八方・無限貫通） |
| 🕊️ カモメ | カモメが鯖へ急降下 | 🎏 大漁旗 | ✈️ カモメ艦隊（爆撃） |
| 🎣 一本釣り | 空から針が降り鯖を釣り上げる | 🍽️ 大皿 | 🐋 大漁一本釣り（連鎖） |

パッシブ：鮮度・草履・DHA・緑茶・漁網・大漁旗・ねじり鉢巻・前掛け・大皿・招き猫（運）・出汁（飛び道具の数）。
全部最大まで上げると「鮮度∞」で上限なくダメージがインフレしていく。

### 敵・ボス・イベント

- 鯖：真サバ → ゴマサバ（速い）→ 金華サバ（硬い）→ しめ鯖（酢を吐く）→ サバ缶（転がる）→ バッテラ（分裂）→ 焼きサバ
- ボス：2:30 ヌシサバ（突進）／6:00 サバ缶大魔神（弾幕＋召喚）／10:00 サバ味噌煮将軍（螺旋弾幕）、以降 4 分ごとに「改」「真」「極」と強化
- **20:00 最終ボス「鯖神」**。倒すと完全制覇。その後も延長戦が続く
- 50 秒ごとに赤く光る**でかいサバ**（宝箱を落とす）
- **サバの群れ**が画面を横切る／**大漁タイム**（金色の鯖・小判ざくざく）／**時化**（嵐・落雷。近くに落ちると自分も危ない）
- **昼夜サイクル**：朝 → 昼 → 夕方 → 夜（提灯が頼り）
- アイテム：おにぎり／鰹のたたき定食（全回復）／浮き玉（全回収）／砂時計（時間停止）／大漁旗（画面の鯖を一掃）／小判の山。壊せる**樽**からも出る

### やりこみ（データはブラウザに保存）

- **漁協の購買部**：小判で永続強化（攻撃力・HP・回避・リロール・復活など 17 種）
- **漁師（キャラ）6 人**：カツオ太郎／板前の鉄／海女のなぎさ／ふし爺／漁港のタマ（猫）／黄金の漁師。実績で解放
- **難易度**：ふつう／激辛／地獄（小判の倍率アップ）
- **実績 29 種**、**番付**（自己ランキング TOP10）、**図鑑**、**設定**（音量・画面揺れ・ダメージ表示・画質）
- **結果をシェア**：最後の瞬間のスクリーンショット入りの結果画像を自動生成。スマホは共有メニューから X などへ画像付きでポストでき、共有メニューがない PC では画像を保存して投稿文をコピーする

## 技術

- 素の HTML + ES Modules + [three.js](https://threejs.org/) r170（`js/vendor/` に同梱、ビルド不要）
- 鰹・鯖・バッテラ・樽などのモデルとテクスチャは**すべてコードで手続き生成**
- 効果音・BGM も WebAudio でその場で合成（音声ファイルなし）
- 外部アセット・サーバー・課金サービス一切なし → **開発・運用コスト 0 円**

```
index.html       画面レイアウト
style.css        UI
js/main.js       ゲーム本体（敵・武器・ボス・イベント・UI）
js/data.js       武器・敵・キャラ・購買部・実績などのデータ
js/save.js       セーブデータ（localStorage）
js/fish.js       鰹・鯖などの手続き生成モデル
js/human.js      主人公モデル
js/audio.js      効果音・BGM
js/vendor/       three.js (MIT)
```

## ローカルで動かす

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

## GitHub Pages で公開する（0 円）

1. `main` ブランチに push する
2. リポジトリの **Settings → Pages** を開く
3. **Source** を「Deploy from a branch」、**Branch** を `main` ／ `/ (root)` にして **Save**
4. 1〜2 分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べる

## デバッグ用 URL パラメータ

- `?debug` … T: 1分進める / L: レベルアップ / B: ボス / K: 雑魚全滅 / G: ゲージ満タン / C: 全武器Lv8 / V: 宝箱 / Y: 小判 / U: 時化 / O: 大漁タイム / H: 20分へ / I: 無敵
- `?auto` … 自動操作 ／ `?turbo=N` … 高速シミュレーション ／ `?god` … 無敵
