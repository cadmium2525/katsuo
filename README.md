# 🐟 カツオのたたきサバイバー

**やたらリアルな鰹**で、迫り来る**鯖**の大群をぶっ叩く 2.5D サバイバーゲーム。
生き延びた時間がそのままスコア。何分耐えられるか競おう。

## 遊び方

| 操作 | PC | スマホ |
| --- | --- | --- |
| 移動 | WASD / 矢印キー | 画面をドラッグ（バーチャルスティック） |
| 攻撃 | 自動 | 自動 |
| 一時停止 | Esc / P | 右下の ⏸ |
| サウンド | M | 右下の 🔊 |
| レベルアップ選択 | 1 / 2 / 3 キー or クリック | タップ |

- 鯖を倒すと**鱗（経験値）**を落とす。集めてレベルアップし、3 択から強化を選ぶ。
- 時間とともに鯖は**インフレ**していく（HP は指数関数的に増加、種類も増える）。
- 2:30 / 6:00 / 10:00、以降 4 分ごとに**ボス**が出現。倒すと宝箱と「鰹の覚醒」（全ダメージ ×1.25 累積）。
- 50 秒ごとに赤く光る**でかいサバ**（エリート）が出現。倒すと宝箱。

### 武器

| 武器 | 内容 |
| --- | --- |
| 🐟 鰹のたたき | 初期武器。鰹で周囲をぶっ叩く。Lv4 で往復ビンタ、Lv8 で 360° 大回転 |
| 🔥 藁焼きの炎 | 周囲を炙るオーラ。取得すると鰹が藁焼きで香ばしくなる |
| 🪃 投げ鰹 | ブーメランのように鰹を投げる（貫通） |
| 🍂 鰹節ショット | 削りたての鰹節を飛ばす貫通弾 |
| 🍋 ポン酢の沼 | 床にポン酢をぶちまけ、鯖を減速＆継続ダメージ |
| 🧄 薬味オービット | にんにく・生姜・ネギが周囲を回転 |

パッシブ：鮮度（攻撃力）・草履（移動速度）・DHA（最大HP）・緑茶（自然回復）・漁網（回収範囲）・大漁旗（経験値）・ねじり鉢巻（クールダウン）・前掛け（防御）・大皿（範囲）。
全部最大まで上げると「鮮度∞」で上限なくダメージを伸ばせる。

### 敵

真サバ → ゴマサバ（1:00〜 速い）→ 金華サバ（3:00〜 硬い）→ サバ缶（5:00〜 転がる）→ 焼きサバ（8:00〜）
ボス：ヌシサバ（突進）／サバ缶大魔神（弾幕＋召喚）／サバ味噌煮将軍（螺旋弾幕＋突進）。周回するたびに「改」「真」「極」と強化される。

## 技術

- 素の HTML + ES Modules + [three.js](https://threejs.org/) r170（`js/vendor/` に同梱、ビルド不要）
- 鰹・鯖のモデルとテクスチャは**すべてコードで手続き生成**（体型プロファイル・鰭・小離鰭・腹の縦縞・鯖の虫食い模様など）
- 効果音・BGM も WebAudio でその場で合成（音声ファイルなし）
- 外部アセット・サーバー・課金サービス一切なし → **開発・運用コスト 0 円**
- 自己ベストはブラウザの localStorage に保存

```
index.html       画面レイアウト
style.css        UI
js/main.js       ゲーム本体（敵・武器・ボス・UI）
js/fish.js       鰹・鯖モデルの手続き生成
js/human.js      主人公モデル
js/audio.js      効果音・BGM
js/vendor/       three.js (MIT)
```

## ローカルで動かす

ES Modules を使うため、ファイルを直接開くのではなくローカルサーバー経由で開く。

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

## GitHub Pages で公開する（0 円）

1. このリポジトリを GitHub に push する（`main` ブランチにマージ）
2. リポジトリの **Settings → Pages** を開く
3. **Build and deployment → Source** を「Deploy from a branch」にする
4. **Branch** を `main`、フォルダを `/ (root)` にして **Save**
5. 1〜2 分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べる

（ビルド工程はないので、push するだけで更新が反映される）

## デバッグ用 URL パラメータ

- `?debug` … T: 1分進める / L: レベルアップ / B: ボス出現 / K: 雑魚全滅 / I: 無敵切替
- `?auto` … 自動操作（動作確認用）
- `?turbo=N` … 1フレームに N ステップ進める（バランス確認用）
